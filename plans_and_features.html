🔄 System Changes & Updates Summary

  • Single School Optimization: Removed all multi-campus selection dropdowns, region configs, and currency select menus. The system is now dedicated entirely to serving a single school environment.
  • Company Logo & Branding: Replaced the generic graduation cap icon with the stylized split Z logo framed inside a premium white square border. Color schemes updated to match the company colors (Deep Blue #0b4d8c and Bright Sky Blue #00a2e8).
  • On-Click Feature Locks: Instead of hiding dashboard links for lower-tier plans, all modules are fully visible on the sidebar. When a user clicks a restricted link, a premium glassmorphic Plan Upgrade Required screen is displayed, prompting them to upgrade to Gold or Platinum.
  • Streamlined Dashboard Home: Removed the generic "Quick Overview" list and static "Features" details cards to make the dashboard workspace cleaner and faster to navigate.
